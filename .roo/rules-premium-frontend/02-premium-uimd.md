# Premium UI Standards

The visual result must feel intentionally designed.

Prioritize:

- typography
- composition
- spacing
- hierarchy
- alignment
- imagery
- contrast
- responsive behavior
- interaction quality

Avoid:

- generic AI layouts
- excessive cards
- excessive rounded corners
- excessive gradients
- excessive shadows
- unnecessary glassmorphism
- visual clutter
- arbitrary decorative elements

Every visual element should have a purpose.
