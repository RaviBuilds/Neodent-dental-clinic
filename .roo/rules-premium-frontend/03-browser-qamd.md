# Browser QA Standards

When Playwright MCP is available, browser inspection is required for meaningful frontend visual tasks.

Inspect the actual rendered page.

Check:

- desktop
- tablet where relevant
- mobile
- typography
- spacing
- layout
- images
- CTAs
- interactions
- overflow
- accessibility
- runtime errors

After implementation, re-render and inspect again.

Do not claim a visual task is complete based solely on source-code inspection.
